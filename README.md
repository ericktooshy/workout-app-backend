# Workout Application Backend API

## Project Description
A robust backend API for a workout tracking application designed for personal trainers. It allows users to track workouts and exercises, and link reusable exercises to specific workouts with dedicated set and repetition counts. The API enforces data integrity through SQL constraints, model-level SQLAlchemy validations, and Marshmallow schema validations.
